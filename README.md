# citizen-counter

Консольная утилита на Go для подсчета частоты имен в текстовом файле.

## Возможности

- Подсчет количества повторений каждого имени в файле
- **Два режима обработки**: последовательный (sequential) и параллельный (parallel)
- Настраиваемый размер буфера чтения файла
- Сортировка результатов по частоте или по алфавиту
- Вывод первых N результатов

## Установка

### Из исходников

```bash
git clone https://github.com/IliaSotnikov2005/citizen-counter.git
cd citizen-counter
go build -o citizen-counter ./cmd/
```
## Использование

### Последовательный режим
```bash
# С параметрами по умолчанию
./citizen-counter file.txt

# Используя свои параметры
./citizen-counter -top=50 -buf=128 -sort=true file.txt
```
### Параллельный режим
```bash
# Автоматическое определение количества CPU
./citizen-counter -mode=parallel file.txt

# С указанием параметров: 4 воркера, буфер 256 МБ, 100 первых результатов
./citizen-counter -mode=parallel -workers=4 -buf=256 -top=100 file.txt
```

## Параметры
| Параметр | Значение по умолчанию | Описание |
|----------|----------------------|----------|
| `-mode` | `sequential` | Режим обработки: `sequential` или `parallel` |
| `-workers` | `0` (авто = CPU cores) | Количество воркеров для параллельного режима |
| `-top` | `20` | Показать первые N имен (0 = все) |
| `-buf` | `64` | Размер буфера чтения в мегабайтах |
| `-sort` | `true` | Сортировать по частоте (`false` = по алфавиту) |
